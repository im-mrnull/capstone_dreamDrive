# DreamDrive Context Rule

## Before exploring the codebase

Always read `docs/_index.md` FIRST for a structured overview of the project.
Only read specific script files when you need implementation details.

## Vault structure (raw / wiki / output)

- `docs/raw/` — unprocessed captures (meeting notes, research dumps, AI logs)
- `docs/wiki/` — polished knowledge notes (completed work, TODOs, architecture)
- `docs/output/` — deliverables (report sections, presentations, paper drafts)

## Context hierarchy (read in this order, stop when you have enough)

1. `docs/_index.md` — master project map, file locations, results summary
2. `docs/wiki/<topic>.md` — detailed notes on specific topics
3. Actual source files in `scripts/`, `tests/` — only when modifying code

## Key facts (saves reading 35KB README)

- **Best model:** Trajectron++ most-likely, test ADE 2.58±0.04
- **Dataset:** IDD-3D, 105 scenes, 10,576 agents, world-frame (ego-compensated)
- **Split:** 73/10/22 train/val/test (frozen, `splits/scene_splits.json`)
- **Provenance:** Every result must trace to a committed JSON artifact. CI enforces this.
- **Retraction history:** Earlier versions had fabricated results. All retracted. See CI guards.

## File conventions

- Result artifacts: `outputs/benchmark_v2/{model}_seed{0,1,2}.json`
- Checkpoints: `outputs/benchmark_v2/{model}_ckpt_seed{0,1,2}.pt`
- Tables are autogenerated: `scripts/make_tables.py` (never hand-edit README tables)
- Tests: `tests/test_*.py` — run with `pytest`

## DO NOT

- Fabricate or hallucinate any result numbers
- Hand-edit autogenerated table sections in README.md
- Modify frozen splits or canonical dataset without explicit approval
- Skip reading `docs/_index.md` and go straight to scanning the whole repo
