# Benchmark v2 Results (Headline Numbers)

## Status: ✅ Fully Done — CI-Enforced Provenance

## Protocol

- Data: `canonical_world_obs20_pred60.npz` — 10,576 agents, world-frame
- Split: `scene_splits.json` — 73/10/22, hash-based
- Seeds: {0,1,2} for neural models, cells are mean±std
- Metrics: masked ADE over valid future steps; FDE at last valid step
- Table autogenerated by `scripts/make_tables.py --check` (CI blocks hand-edits)

## Key Takeaways

1. **Trajectron++ most-likely is best deployable** — clearly ahead of all others
2. **Interaction modeling works on full population** — ST-GAT beats CV/MLP (was reversed in v1)
3. **Mode selection is the bottleneck** — K-mode oracle (1.88) vs top-1 (4.31) = huge gap
4. **Test set is genuinely harder** — 1.2–1.8× val ADE for every model
