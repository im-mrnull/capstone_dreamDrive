# Bootstrap Confidence Intervals

## Status: ✅ Done (Oct 2026) — `scripts/bootstrap_ci.py`, `scripts/dd_bootstrap.py`

## What it does

Scene-level percentile bootstrap over the 22 **test scenes** (10,000 resamples). Agents
in a scene are correlated (shared ego drive, layout, interactions; plus up to 7 overlapping
windows per agent), so the scene is the resampling unit, not the agent.

For each deployable model (seed-0 checkpoint, from its prediction dump):
- test ADE / FDE with 95% CI;
- **paired** differences between models adjacent in the ranking (same resample for both
  models → shared scene difficulty cancels);
- per-class ADE CIs and a CI on the worst/best class disparity.

Point estimates are cross-checked against the seed-0 metrics JSONs (all match).

## Findings (seed-0 dumps; see `outputs/benchmark_v2/bootstrap_ci.json` for final numbers)

Final run 2026-10-27, all models on the same 2,177 canonical test windows.

1. **Absolute CIs are wide.** Lowest-ADE model (ST-GAT) 3.33 m [2.16, 4.98]. Never compare an
   absolute ADE from this split with one from another dataset/split.
2. **Two tiers.** ST-GAT vs map-free transformer is a **tie** (Δ −0.10, CI [−0.36, 0.13]).
   Transformer vs LED is **separated** (Δ −0.31, CI [−0.66, −0.08]). LED ≈ AgentFormer ≈
   Trajectron++ ≈ MLP ≈ K-mode ≈ CV are adjacent ties. ST-GAT is separated from every model
   except the transformer.
3. **Caveat:** one dump per model (seed 0) — the transformer's best seed (3.43 vs 3.71 / 3.58).
   A seed-pooled bootstrap needs the seed-1/2 dumps.
4. **Class disparity** (n ≥ 50 classes): ST-GAT 12.5×, CI 6.7–24.0× (worst Car, best Scooter).
5. *Withdrawn:* "Trajectron++ > ST-GAT separated" — Trajectron++'s dump was on its easier
   dense population; see [[benchmark-v2]].
