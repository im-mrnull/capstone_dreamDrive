## Status: ✅ Fully Done

## Finding: 16× ADE Disparity Across Classes

Best deployable model (Trajectron++ most-likely), test split:

| Class | n | ADE (m) | ADE/path-m |
|-------|---|---------|-----------|
| MotorcyleRider | 4000 | 3.20 | 0.164 |
| Car | 3402 | 4.08 | 0.233 |
| ScooterRider | 3632 | 3.43 | 0.184 |
| Pedestrian | 3915 | 0.76 | 0.245 |
| PoliceCar | 123 | 2.19 | **0.548** |
| Animal | 159 | 0.25 | 0.233 |
| Van | 224 | 0.56 | 0.134 |

**Key insight:** Raw ADE tracks path length (fast classes look worse). But ADE *per meter
traveled* flips the story — erratic slow agents (pedestrians: 0.245/m) are relatively
harder than fast predictable ones (motorcycle riders: 0.164/m).

## Motivation for Class-Conditional Conformal

This 16× disparity directly motivates per-class conformal radii (see conformal-prediction.md).
A single global radius under-covers fast classes and over-covers slow ones.
