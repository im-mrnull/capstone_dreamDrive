# Per-Class Fairness Audit

## Status: ✅ Fully Done

## Finding: ~10–13× ADE Disparity Across Classes (n ≥ 50)

Lowest-ADE deployable model (ST-GAT-inspired, MHA; tied with the map-free transformer),
test split, canonical windows:

| Class | n | ADE (m) | ADE/path-m |
|-------|---|---------|-----------|
| MotorcyleRider | 396 | 4.12 | 0.161 |
| Pedestrian | 372 | 1.10 | 0.263 |
| Car | 336 | 5.25 | 0.209 |
| ScooterRider | 328 | 5.38 | 0.187 |
| Truck | 278 | 2.56 | 0.217 |
| TourCar | 247 | 4.62 | 0.203 |
| Scooter | 50 | 0.53 | **0.328** |

Disparity (worst/best class, n ≥ 50): 10.25× in the README audit table (one representative
seed); 12.5×, scene-bootstrap 95% CI 6.7–24.0× for the seed-0 dump ([[bootstrap-ci]]).

**Key insight:** Raw ADE tracks path length (fast classes look worse). But ADE *per meter
traveled* flips the story — slow, erratic agents (scooters 0.328/m, pedestrians 0.263/m)
are relatively harder than fast ones (motorcycle riders: 0.161/m).

## Motivation for Class-Conditional Conformal

This disparity directly motivates per-class conformal radii (see [[conformal-prediction]]).
A single global radius under-covers fast classes and over-covers slow ones.
